## 로드밸런싱
- 대충 envoy 설정만 잘 하면 문제 없음 ㅇㅇ

## 속도 
### 방식
- 프론트(html)에서 (응답 온 시간) - (요청 보낸 시간) 으로 계산
- 모든 html 코드는 gemini 행님이 만들어주심 
> 일관성 1도 없고 진짜 대충대충 해보려고 그냥 넘김
- envoy 내 특정 설정이 꺼져있을것임(인증필터, gRPC 필터 등?)
- spring 테스트 코드가 "/"로 라우팅 되어있을거임. 오류뜨는거 귀찮아서 대충 해놨는데 나중에 수정해야함

- 인증 필터 X > 웹소켓 첫 연결시에만 인증필터 거치므로 채팅 시간에 영향 x
- 정답 확인 x > 안 만듬. 유일하게 6번, 운석이형이 만든 signalR 코드에만 존재함 


### 테스트 결과

- socket io 평균 RTT : 3.62ms
- ws (raw websocket) 평균 RTT : 3.00ms

- stomp : 평균 RTT: 5.32 ms
- raw ws (메시지 브로커 x) : 평균 RTT: 약 2.97 ms 

- signalR (메시지 브로커 x): 평균 RTT: 약 2.96 ms
- signalR (메시지 브로커 redis ):평균 RTT: 약 3.89 ms
